# 🎬 Netflix Clone (HTML & CSS)

A responsive **Netflix landing page clone** built using **HTML5** and **CSS3** as part of the **Sigma Web Development Course by CodeWithHarry**. This project focuses on creating a modern, responsive user interface inspired by Netflix while improving frontend development skills.

## 🚀 Features

* Responsive design for different screen sizes
* Modern Netflix-inspired UI
* Hero section with call-to-action
* Navigation bar
* FAQ section
* Footer
* Clean and organized HTML & CSS code

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📚 What I Learned

* Writing semantic HTML
* Styling layouts with CSS
* Flexbox
* Responsive Web Design
* Media Queries
* CSS positioning and layout techniques
* Building real-world frontend projects

## 📂 Project Structure

```text
Netflix-Clone/
│── assets/
│── index.html
│── style.css
└── README.md
```


## 🎯 Purpose

This project was built for learning and practicing frontend web development by recreating the Netflix landing page using only HTML and CSS.
